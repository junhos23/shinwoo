# 신우코맥스 마케팅 작업 규칙

사업 기획 매니저와 함께 신우코맥스의 마케팅 홈페이지와 관리 대시보드를 만든다.
새 규칙이 생기면 아래 "규칙" 목록 끝에 번호를 이어 추가하고, 변경 이력에 한 줄 남긴다.

## 회사 정보

출처: 대표 명함 (작업 폴더의 `신우코맥스_*.jpeg`, git에는 올리지 않음)

- 회사명: 신우코맥스 (명함 표기 "신우 코맥스"), 영문 SHINWOO COMMAX
- 위치: 경기도 성남시 분당구 궁내동 281-9 202호
- 대표전화 031-706-0993 · 팩스 031-709-0993
- 업종: 코맥스 대리점. 명함 문구 "COMMAX HomeNetwork", "Home Mobile System 시공 전문 업체". 홈오토메이션(월패드·비디오폰), 출입통제, 네트워크 공사
- 대표: 원충연. 대표 이메일은 홈페이지 문의하기에 게시했다(사용자 요청, 2026-11-06). 대표 휴대폰 번호는 홈페이지에 쓰지 않는다.
- **홈페이지의 전화번호는 모두 회사 대표전화(031-706-0993)로 통일한다.** 전화 상담·문자 보내기 버튼도 대표전화로 연결한다.
- 아직 모르는 정보(사업자등록번호 등)는 임시 값으로 두고 `<!-- 실제 ... 로 바꿔 주세요 -->` 주석을 단다. 임의로 지어내지 않는다.

## 규칙

1. **배경색은 밝은색**을 쓴다. 기본 배경 `#ffffff`, 보조 배경 `#f4f7fa`. 다크 모드는 따로 요청이 없으면 만들지 않는다.
2. **폰트는 Pretendard**를 쓴다. 웹에서는 아래 CSS를 불러오고 `font-family: "Pretendard", system-ui, sans-serif;`로 지정한다.
   `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css`
3. **브랜드 색**: 메인 블루 `#0b5cad`, 딥 블루 `#083f78`, 포인트 청록 `#16b3a0`, 본문 `#13202e`, 보조 글자 `#566577`, 선 `#e1e7ed`.
4. **로고 (다시 정하는 중)**: 지금 홈페이지에 들어간 로고는 "집 + S" 심볼과 문구 "출입통제 · 홈네트워크 · CCTV 시공 전문"이다(`assets/logo/`, `node tools/build-logo.js`로 생성). 사용자가 이 로고를 마음에 들어 하지 않아 새 심볼을 고르는 중이다. 방향은 **열린 문** 심볼, **블루 #0b5cad + 청록 #16b3a0 투톤**(2026-11-06). 확정되면 `tools/build-logo.js`의 심볼을 바꿔 파일을 다시 만들고 홈페이지 상단 로고도 바꾼다.
5. **코맥스(COMMAX) 상표**: 코맥스 로고나 상표 디자인을 흉내 내지 않는다. "코맥스 대리점"이라는 사실을 글자로 표기하는 것만 한다.
6. **조사·사실 근거**: 웹에서 찾은 내용은 출처 링크를 남긴다. 확인하지 못한 수치나 사실은 쓰지 않거나 "확인 필요"로 표시한다. 예시 데이터는 "(예시)"라고 표시한다.
7. **개인정보·인증정보**: 명함·엑셀 등에 들어 있는 개인정보는 사내 보안 정책을 따른다. 주민등록번호·계좌번호·카드번호 등은 처리하지 않고, 비밀번호·토큰·API 키는 입력받거나 저장하지 않는다.
8. **형상관리**: 결과물은 git으로 관리한다. 의미 있는 작업 단위마다 한국어 커밋 메시지로 커밋한다. 저장소는 GitHub `junhos23/shinwoo`(공개, `main` 브랜치). 홈페이지는 GitHub Pages로 `main`의 루트를 배포한다 → https://junhos23.github.io/shinwoo/ . push하면 1~2분 뒤 공개 홈페이지에 반영된다. push는 사용자가 요청할 때 한다.
9. **관리 대시보드**: 사용자가 올린 엑셀 파일을 읽어서 만든다. 원본 엑셀은 수정하지 않는다. 파일이 오기 전에는 화면 틀만 만들고 가짜 수치로 채우지 않는다.
10. **원본 자료는 git 제외**: 명함 이미지, 원본 엑셀처럼 개인정보가 들어 있을 수 있는 사용자 자료는 `.gitignore`에 넣어 커밋하지 않는다.
11. **작업 폴더**: `문서\Claude\신우` (사용자 지정). 사용자 자료도 이 폴더에 저장된다. 자료를 못 찾으면 이 폴더부터 확인한다.
12. **회사 성격은 "대리점"**: 신우코맥스는 제조사가 아니라 코맥스 대리점(판매·시공·A/S)이다. 제조사처럼 보이는 표현("자체 개발", "글로벌 브랜드" 등)을 쓰지 않는다.
13. **참고 사례는 대리점·시공업체 수준**: 로고·홈페이지를 조사할 때 제조사(코맥스·코콤·현대에이치티·해외 브랜드) 사이트는 기준으로 삼지 않는다. 영상이 없는 가벼운 페이지를 가진 지역 대리점·시공업체 사이트를 참고한다.
14. **홈페이지는 가볍게**: 배경 영상, 무거운 슬라이드, 큰 애니메이션을 넣지 않는다. 사진 몇 장과 글, 전화·견적 버튼 중심으로 만든다.
15. **로고는 실제 쓰임새로 검토**: 초안마다 명함, 차량·간판(가로로 긴 자리), 작은 아이콘에 넣은 모습을 함께 보여 준다.
16. **사진은 저작권 문제가 없는 것만**: 실제 시공 사진이 없으면 Unsplash 무료 이미지(Unsplash+ 유료 제외)를 쓰고, 사진에 "참고 이미지" 표시를 붙이고 `assets/cases/SOURCES.md`에 원본 주소를 적는다. 사람 얼굴·이름·상표가 크게 보이는 사진은 피한다.
17. **문의하기는 연락처만**: 홈페이지에 문의 보내기 폼을 넣지 않는다. 문의하기 영역에는 연락처 목록만 두고, 그 아래에 전화 상담·문자 보내기 버튼을 만들지 않는다(사용자 지적, 2026-11-06). 휴대폰 화면 하단에 붙는 전화·문자 버튼도 만들지 않는다(사용자 요청, 2026-11-06). 전화 버튼은 상단 "전화 상담" 하나만 둔다.
18. **상단 로고는 어느 화면에서나 보이게**: 심볼은 PNG를 data URI로 페이지에 직접 넣고, 회사명 "신우코맥스"는 이미지가 아닌 HTML 글자(Pretendard 800)로 쓴다. 일부 미리보기 화면은 SVG·외부 이미지를 표시하지 않아 회사명이 사라진 적이 있다(2026-11-06, 두 번 지적받음). 로고를 바꾸면 `npm run logo` 후 이 부분도 다시 넣는다.
19. **오시는 길 = 구글 지도 + 네이버 버튼**: 구글 지도를 iframe(`maps.google.com/maps?q=주소&output=embed`)으로 페이지에 띄우고, 그 아래에 "네이버 지도 보기" 버튼만 둔다. 주소는 도로명 "경기 성남시 분당구 대왕판교로 301". 키가 필요 없다. 카카오·네이버 지도는 페이지 안에 띄우려면 키가 필요해서 쓰지 않기로 했다(2026-11-06, 사용자 결정).
20. **로고 샘플은 파일 하나로**: 샘플은 `logo-samples.html`(보기 페이지)과 `logo-samples.png`(비교 이미지) 하나만 두고, 새 샘플을 만들 때마다 이 두 파일을 덮어써서 업데이트한다. `logo-samples-2`처럼 번호 붙은 새 파일을 만들지 않는다(사용자 요청, 2026-11-06). 이전 샘플은 git 기록에 남는다.
